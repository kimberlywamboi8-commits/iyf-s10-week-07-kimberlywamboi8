This project is a refactored To-Do List application built with HTML, CSS, and JavaScript.
It uses `localStorage` to save tasks so they remain available after refreshing or reopening the browser. 
It also uses `sessionStorage` to save the current text in the input field during the active session.
The code was improved by organizing it into clear sections, using functions for repeated actions, and adding comments to make it easier to read and maintain.
This project demonstrates state persistence, cleaner code structure, and basic best practices in JavaScript.
